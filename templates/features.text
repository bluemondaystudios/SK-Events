Artist Profile features: 
            -Most famous social link platform (External Credibility)
            -Audio Upload: Best Record
            -Artist name platform

Every profile exists as an ID-like card in this user profile... just on top of the 'Available Events'/'My Events' and 'Booking Requests' under each card
This card is generated as a template to fill in the necessary info... the info is complete if : Social Media Link, Artist Stage Name, Best Song have been filled in
The "id" card is embedded with SK EVENTS branding..blending seamlessly with the current theme, WHICH I LOVE! 



Artist Action:

        There is ONLY ONE important action for each profile. 
        The artist can only request an organiser to 'Book Me'

        HOWEVER...

        The artist must still see that his/her request is in.
        <request status>

        HOW?

        The artist profile must reflect the booking: PENDING, ACCEPTED or DECLINED.
        The business model with the partners..."rather leave a declined artist pending, they only have ONE chance to hit Book Me."


Event Organiser Action:

         There is ONLY ONE important action for each profile.
         The organiser can only respond to a 'Book Me': ACCEPT, DECLINE or WAIT/IGNORE (PENDING)
